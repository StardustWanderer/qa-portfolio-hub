# Ручное тестирование

Проекты по тестированию веб- и мобильных приложений, а также REST API.

В рамках работ выполнялись анализ требований, тест-дизайн, разработка чек-листов и тест-кейсов, функциональное, регрессионное, UI- и API-тестирование, регистрация дефектов и анализ результатов проверок.

Все проекты и тестовая документация хранятся на Google Drive. Ссылки ведут на папки соответствующих проектов.

## Дипломный проект

### Яндекс Самокат — тестирование веб- и мобильного приложений

Комплексный проект по тестированию веб-приложения Яндекс Самокат и проектированию тестов для мобильного приложения курьеров.

**Веб-приложение:**
- Анализ требований и макетов Figma.
- Функциональное и UI-тестирование экрана «Статус заказа».
- Проверка валидации полей формы оформления заказа с применением классов эквивалентности и граничных значений.
- Проверка бизнес-логики заказов, их статусов и отмены.
- Исследовательское тестирование за пределами подготовленной документации.
- Кросс-браузерное тестирование.
- Использование Postman для подготовки тестовых данных и управления состояниями заказов.

**Мобильное приложение курьеров:**
- Анализ требований и макетов.
- Проектирование тест-кейсов для push-уведомлений.
- Проверки системных разрешений, состояний устройства и приложения.
- Проектирование проверок обработки отсутствия интернет-соединения.

**Результаты:**
- 238 проверок экрана «Статус заказа».
- Таблица тестовых данных для валидации 9 полей.
- 77 баг-репортов: 51 UI-дефект, 15 дефектов валидации и 11 функциональных дефектов.
- 39 тест-кейсов для мобильного приложения курьеров.

*Фактическое тестирование мобильного приложения не проводилось: вторая часть проекта предусматривала проектирование тестовой документации.*

**Инструменты:** Google Sheets, Postman, Figma, Google Chrome, Яндекс Браузер, Chrome DevTools.

**Материалы проекта:** [Google Drive](https://drive.google.com/drive/folders/1cK0d9xuMK1KzksjJgXFhmGqSMUXgQiPd?usp=drive_link)

# Java Core и автоматизация тестирования

Проекты по освоению Java и автоматизации тестирования веб-приложений и REST API.

В работах применялись ООП, коллекции Java, JUnit 4, Mockito, JaCoCo, Selenium WebDriver, REST Assured и Allure Report.

Все проекты размещены в отдельных GitHub-репозиториях.

## Дипломные проекты

### Diplom_1 — юнит-тестирование класса Burger

Юнит-тестирование бизнес-логики Java-приложения Stellar Burgers. Основной объект тестирования — класс `Burger`, отвечающий за состав бургера, расчёт стоимости и формирование чека.

**Выполнено:**
- Написание тестов для основных методов класса `Burger`.
- Использование Mockito для создания мок-объектов и настройки стабов.
- Проверка операций добавления, удаления и перемещения ингредиентов.
- Проверка расчёта стоимости с помощью параметризованных тестов.
- Проверка формирования текстового чека.
- Анализ покрытия тестами с помощью JaCoCo.

**Результат:** 100% покрытия класса `Burger` по отчёту JaCoCo.

**Технологии:** Java 11, JUnit 4, Mockito, JaCoCo, Maven.

**Репозиторий:** [Diplom_1](https://github.com/StardustWanderer/Diplom_1)

### Diplom_2 — API-тесты Stellar Burgers

Автоматизация тестирования REST API сервиса Stellar Burgers.

**Выполнено:**
- Проверка регистрации пользователей: успешный и негативные сценарии.
- Проверка авторизации с корректными и некорректными данными.
- Проверка создания заказов с авторизацией и без неё.
- Проверка обработки запросов без ингредиентов и с невалидным ID ингредиента.
- Получение актуальных идентификаторов ингредиентов через API.
- Генерация динамических тестовых данных.
- Очистка тестовых пользователей после выполнения проверок.
- Интеграция Allure для документирования тестовых сценариев и HTTP-взаимодействий.

**Технологии:** Java 11, JUnit 4, REST Assured, Allure Report, AspectJ Weaver, JavaFaker, Gson, Lombok, Maven.

**Репозиторий:** [Diplom_2](https://github.com/StardustWanderer/Diplom_2)

### Diplom_3 — UI-тесты Stellar Burgers

Автоматизация пользовательских сценариев веб-приложения Stellar Burgers с использованием Selenium WebDriver и паттерна Page Object.

**Выполнено:**
- Проверка успешной регистрации пользователя и обработки некорректного пароля.
- Проверка авторизации через четыре точки входа в приложение.
- Проверка переключения вкладок конструктора бургеров.
- Реализация Page Object для основных страниц приложения.
- Использование явных ожиданий Selenium.
- Подготовка и удаление тестовых пользователей через REST API.
- Сбор результатов тестирования с помощью Allure.

**Результаты:** 9 тестовых методов, запускаемых в Google Chrome и Яндекс Браузере.

**Технологии:** Java 11, Selenium WebDriver, JUnit 4, REST Assured, Allure Report, AspectJ Weaver, JavaFaker, Gson, Lombok, Maven.

**Репозиторий:** [Diplom_3](https://github.com/StardustWanderer/Diplom_3)
