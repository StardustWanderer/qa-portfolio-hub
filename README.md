# Ручное тестирование

Проекты по тестированию веб- и мобильных приложений, а также REST API. Включают анализ требований, тест-дизайн, функциональные проверки, регистрацию дефектов и анализ результатов тестирования.

Все материалы хранятся на Google Drive.

## Дипломный проект

### Яндекс Самокат — тестирование веб- и мобильного приложений

**Выполнено:**
- Функциональное и UI-тестирование веб-приложения.
- Проверка валидации полей формы с применением классов эквивалентности и граничных значений.
- Кросс-браузерное и исследовательское тестирование.
- Использование Postman для подготовки тестовых данных и управления состояниями заказов.
- Проектирование тест-кейсов для мобильного приложения курьеров.

**Результаты:** 238 проверок экрана «Статус заказа», 77 баг-репортов, 39 тест-кейсов для мобильного приложения.

*Мобильное приложение фактически не тестировалось — выполнялось проектирование тестовой документации.*

**Инструменты:** Google Sheets, Postman, Figma, Chrome, Яндекс Браузер, Chrome DevTools.

**Материалы:** [Google Drive](https://drive.google.com/drive/folders/1cK0d9xuMK1KzksjJgXFhmGqSMUXgQiPd?usp=drive_link)

# Java Core и автоматизация тестирования

Проекты по освоению Java и автоматизации тестирования с использованием JUnit, Mockito, Selenium WebDriver и REST Assured.

Все проекты размещены в отдельных GitHub-репозиториях.

## Дипломные проекты

### Diplom_1 — юнит-тестирование класса Burger

- Проверка бизнес-логики класса `Burger`.
- Использование Mockito для создания мок-объектов и настройки стабов.
- Параметризованные тесты расчёта стоимости.
- Проверка формирования чека.
- Анализ покрытия с помощью JaCoCo.

**Результат:** 100% покрытия класса `Burger`.

**Технологии:** Java 11, JUnit 4, Mockito, JaCoCo, Maven.

**Репозиторий:** [Diplom_1](https://github.com/StardustWanderer/Diplom_1)

### Diplom_2 — API-тесты Stellar Burgers

- Автоматизация проверок регистрации и авторизации пользователей.
- Проверка создания заказов с авторизацией и без неё.
- Позитивные и негативные API-сценарии.
- Получение актуальных ID ингредиентов через API.
- Генерация и очистка тестовых данных.
- Интеграция Allure для отчётности.

**Технологии:** Java 11, JUnit 4, REST Assured, Allure, AspectJ Weaver, JavaFaker, Gson, Lombok, Maven.

**Репозиторий:** [Diplom_2](https://github.com/StardustWanderer/Diplom_2)

### Diplom_3 — UI-тесты Stellar Burgers

- Автоматизация регистрации и авторизации пользователей.
- Проверка четырёх способов перехода к форме входа.
- Проверка вкладок конструктора бургеров.
- Реализация Page Object Model и явных ожиданий Selenium.
- Подготовка и удаление тестовых пользователей через REST API.
- Сбор результатов тестирования с помощью Allure.

**Результаты:** 9 тестовых методов с запуском в Google Chrome и Яндекс Браузере.

**Технологии:** Java 11, Selenium WebDriver, JUnit 4, REST Assured, Allure, JavaFaker, Gson, Lombok, Maven.

**Репозиторий:** [Diplom_3](https://github.com/StardustWanderer/Diplom_3)

- Получение уникальных имён с помощью `Set`.

- Обработка исключений и форматирование строк через `StringBuilder`.

### Автоматизация тестирования

#### Sprint 4 — UI Automation Tests (Яндекс Самокат)

- Параметризованная проверка восьми элементов FAQ.
- Автоматизация оформления заказа через две кнопки на главной странице.
- Проверка финального модального окна.
- Реализация Page Object Model.
- Явные ожидания Selenium и динамическое формирование дат.

**Результаты:** 2 параметризованных тестовых метода, 10 запусков на один браузер.

*В Chrome воспроизводится известный дефект приложения: после подтверждения заказа не появляется финальное окно. Проверка сохраняет ожидаемое поведение и не подавляет ошибку.*

**Технологии:** Java 11, Selenium WebDriver, JUnit 4, Maven.

**Репозиторий:** [Sprint_4](https://github.com/StardustWanderer/Sprint_4)

#### Sprint 6 — юнит-тестирование Cat, Feline и Lion

- Проверка классов `Cat`, `Feline` и `Lion`.
- Изоляция зависимостей с помощью Mockito.
- Использование моков, стабов и шпионов.
- Параметризованное тестирование и проверка исключений.
- Реализация дополнительного класса `AlexLion`.

**Результат:** 100% покрытия по JaCoCo для классов `Cat`, `Feline`, `Lion` и `AlexLion`.

**Технологии:** Java 11, JUnit 4, Mockito, JaCoCo, Maven.

**Репозиторий:** [Sprint_6](https://github.com/StardustWanderer/Sprint_6)

#### Sprint 7 — API-тестирование Яндекс Самоката

- Автоматизация создания и авторизации курьера.
- Проверка создания заказов с различными вариантами цвета самоката.
- Проверка получения списка заказов.
- Параметризованное тестирование с JUnit 4.
- Генерация тестовых данных с JavaFaker.
- Организация API-запросов с помощью REST Assured.
- Интеграция Allure Report.

**Технологии:** Java 11, JUnit 4, REST Assured, Allure, JavaFaker, Gson, Lombok, AspectJ Weaver, Maven.

**Примечание:** при проверке авторизации курьера без пароля сервер вернул `504 Gateway Timeout` вместо ожидаемого `400 Bad Request`. Особенность зафиксирована в README проекта.

**Репозиторий:** [Sprint_7](https://github.com/StardustWanderer/Sprint_7)
